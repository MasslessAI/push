# Security Policy

Thanks for helping keep Push and its users safe.

## Reporting a vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, report them privately:

- Email **contact@massless.ai**, or
- Use GitHub's [private vulnerability reporting](https://github.com/MasslessAI/push/security/advisories/new) on this repo.

Please include:

- the affected app (macOS / iOS) and version,
- a description of the issue and its impact,
- steps to reproduce, if you have them.

We'll acknowledge your report, keep you updated as we investigate, and credit you (if you'd like) once a fix ships.

Thank you for reporting responsibly.
